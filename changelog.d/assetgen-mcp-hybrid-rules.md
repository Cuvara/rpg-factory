### Changed

- **Asset-gen skills.** `asset-gen`, `comfyui` and `comfy-desktop-setup` now state the rules for hybrid and local ComfyUI workflows: read the `gpu`, `torch` and `profile` rows of `comfy-desktop-setup.py --check` first, resolve with `--profile`, never run a local template on a lower profile, graph-lint the template with `--profile`, never install a pack or download a model without the user's yes, and report the profile, the local models and the seed. The old "no local models" sentence is superseded for machines whose profile meets a template's `requires.profile`. A post-process node may now produce the deliverable when the purpose needs it, named per template. `comfy-desktop-setup` documents the new `comfy-cli`, `gpu`, `torch`, `profile`, `packs` and `models` rows and the exact command that saves `--check --json` as `<state>/assetgen/hardware-profile.json`, which `resolve --profile auto` reads and nothing else writes.
- **Untested on target hardware.** The local and hybrid branch is UNTESTED on RTX 5060 (8 GB): the user tests it after merge. No generation, VRAM number or quality result is claimed.
