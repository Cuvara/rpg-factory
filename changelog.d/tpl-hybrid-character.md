### Added

- **Asset generation.** Add the core template `hybrid-character` for the purposes ref-3d-character, ref-3d-turnaround and sprite-2d, the template `resolve --profile local-8gb` routes them to (`scripts/assetgen/data/template-profiles.json`). The API image node makes the base sheet or pose; a local SDXL stage refines it at 1024 px wide with IPAdapter conditioning from the approved character anchors (`anchor_target`) and one Canny ControlNet, batch 1 and a tiled VAE decode, then a 4x upscale model, a resize to `output_width` and a cut-out feed the one SaveImage. The reviewed prompt is one node feeding the image node and the positive encoder; the seed is a render param; the requires block declares profile local-8gb, the three node packs and the model files by name. A pose or depth ControlNet is the intended swap once known-nodes has that preprocessor. UNTESTED on RTX 5060: the local branch is untested on the RTX 5060 8 GB target hardware; nothing was generated or measured, sampler values are starting points to tune in the live task, and the user will test on that machine after merge.
