### Added

- **Asset-gen local node registry.** UNTESTED on RTX 5060: no local generation, VRAM figure or quality result was measured; the user tests on the RTX 5060 8 GB machine after merge. `known-nodes.json` gains the local SDXL core nodes CheckpointLoaderSimple, CLIPTextEncode, CLIPTextEncodeSDXL, EmptyLatentImage, VAEEncode, VAEDecode, VAEDecodeTiled, KSampler, LoraLoader, ControlNetLoader, ControlNetApplyAdvanced, UpscaleModelLoader and ImageUpscaleWithModel (signatures from the live ComfyUI 0.45.2 `object_info`, listed in `local_model_nodes`), and the pack nodes IPAdapterUnifiedLoader and IPAdapterAdvanced (pack `comfyui_ipadapter_plus`), CannyEdgePreprocessor (`comfyui_controlnet_aux`) and InspyrenetRembg (`cut-out (BiRefNet or rembg)`) under a top-level `packs` map keyed by the `hardware.json` pack id. The pack signatures come from the pack source at pinned commits, not from a running ComfyUI: no saved `object_info` from a machine with the packs existed.
- **Asset-gen template `requires` block.** UNTESTED on RTX 5060: the block is a declaration that lint compares with the planning thresholds of `hardware.json`, never a measured number. A template may declare `requires` with `profile`, `peak_vram_gb`, `ram_gb`, `packs` and `models` (`kind`, `name`, `size_gb`). Lint refuses a missing or unknown profile, an unknown key, a `peak_vram_gb` or `ram_gb` above the profile's `min_vram_gb` or `min_ram_gb`, a pack that is not a pack of the profile or is listed twice, an unknown model kind, a model name that is a path, a host or a link instead of a file name (source links live in the docs, never in templates or scripts), and any link, endpoint or credential inside the block. A workflow node from a registered pack needs its pack id in `requires.packs`, a local model node or pack node needs the block and a profile with a GPU (`requires.gpu` true in `hardware.json`; `api-only` has none and stays valid for a template without such a node), and a declared pack no node uses is a warning. A missing or malformed `hardware.json` is one lint error, not a traceback. Templates without the block and without local nodes lint as before; an unknown node or input is still an error.
