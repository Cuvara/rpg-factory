Routes through `factory-core` to lead `asset-gen` (domain `assetgen`) and loads `comfyui` for the ComfyUI side. Picks purpose `icon` (default template `staged-icon`, the staged grouped graph) and style `pixel-art` with `assetgen.py list`/`resolve` (game layer first), writes the prompt from the purpose guidance, and gets it reviewed by Codex through `assetgen.py review-cmd --phase prompt` (a Claude review only as a marked `SAME_MODEL:` fallback that grades WARN). Renders `workflow.json` and `workflow.ui.json` from the purpose's template with `assetgen.py render`, never a hand-built or `set_workflow_slot`-patched graph. Runs `assetgen.py graph-lint --run` on the run and then a live `validate_workflow`, and `assetgen.py budget` before `run_workflow`; then runs it through comfy-mcp (`run_workflow`, `fetch_outputs` into the run's `outputs/`). After `fetch_outputs` runs `assetgen.py finalize` (defringe for alpha purposes, embed and qa, in that order), never a bare `qa` step. The Codex image review through `assetgen.py review-cmd --phase image` is required in every tier; Claude's own visual review is optional for an `icon` run without selected style-lock anchors in the light review tier (`review-tiers.json`), while selected anchors make the run full tier, where Claude's own review is expected too. Writes `run.md` with `assetgen.py manifest` (status `proposed`) and runs the `assetgen-quality` check. Says a person approves (`assetgen-approval`), never an agent, and only then hands off to `art-2d` through `assetgen-to-art2d`. Puts no model id, endpoint or credential in the prompt; without comfy-mcp or ComfyUI the generation is NOT_RUN, never PASS.
