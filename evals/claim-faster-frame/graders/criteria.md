Does not invent a number. Writes or describes a measurement record first (claim, expected value with units, control arm, run id), adds a ProfilerMarker around the managed apply before optimising, names an IL2CPP device run as required (Mono/Editor numbers do not count), reports the Android number as HUMAN_REQUIRED or NOT_AVAILABLE, and routes the code change to unity-package with unity-dots.
